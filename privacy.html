Purpose

Hermes Workspace is a private personal-assistant integration used by its owner to carry out requested tasks with the owner's Google Workspace data.

Google data accessed

After the user grants OAuth consent, the integration may access Gmail messages and labels, Calendar events, Drive files and metadata, Contacts, Sheets and Docs. Access is limited to the scopes displayed by Google during consent and is used only to perform user-requested functions.

How data is used

  • Read or organise information requested by the user.
  • Create, update or send content only when directed or confirmed by the user.
  • Maintain the authorised connection using Google's OAuth token mechanism.

Google user data is not used for advertising, profiling, credit decisions or training general-purpose AI models.

Storage and security

OAuth credentials and working data are stored in the owner's controlled Hermes environment. Reasonable technical safeguards are used to restrict access. Public web pages in this repository contain no Google user data or credentials.

Sharing and disclosure

Google user data is not sold. It is not shared with third parties except service providers required to fulfil an explicit user request, where the user has authorised that processing, or where disclosure is required by law.

Retention and deletion

Data is retained only as needed for requested functions and local records. The owner can stop access by revoking Hermes Workspace under Google Account connections and deleting locally stored credentials. Deletion questions may be sent to the contact address above.

Limited use disclosure

Hermes Workspace's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Material changes will be posted on this page with a revised effective date.
